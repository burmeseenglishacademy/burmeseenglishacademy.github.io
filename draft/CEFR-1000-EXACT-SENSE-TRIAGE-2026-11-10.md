## Highest-priority exact-sense issue: obfuscate (C1)
- Inventory: `obfuscate`, verb, source `draft/A2-C1-SOURCE-RECOVERY-EDITORIAL-BATCH58.json`, source index 45, source blob `da7df62123acfac89a0acedad4652ec499c7ed3d`.
- Current definition: “To make information deliberately difficult to understand.” Example: “Technical jargon can obfuscate the real reasons for a delay.”
- **Mismatch to adjudicate:** The definition asserts deliberate intention, while the modal `can` example is compatible with accidental obscuring by jargon. Neither the example nor the syntax proves intent. The Myanmar definition likewise explicitly says `ရည်ရွယ်ချက်ရှိရှိ` (“deliberately”). An independent reviewer must decide whether the exact intended sense is intentional concealment or general making unclear; if intentional, the example needs an actor and context showing intention.
- Original alternative example for *deliberate* sense: “The spokesperson deliberately obfuscated the figures to avoid answering the question.” Myanmar draft: “မေးခွန်းကို မဖြေရအောင် ပြောရေးဆိုခွင့်ရှိသူက ကိန်းဂဏန်းများကို ရည်ရွယ်ချက်ရှိရှိ ရှုပ်ထွေးအောင် ပြောဆိုခဲ့သည်။” Check whether `obfuscated the figures` is idiomatic and whether the translation captures obscuring rather than falsification.

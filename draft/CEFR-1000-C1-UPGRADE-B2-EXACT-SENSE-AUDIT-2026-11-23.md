## Bilingual and grammar editorial analysis (unverified proposals)

- `အဆင့်မြှင့်တင်သည်` is broadly appropriate for improving an existing system, but the current English definition **requires replacement**, while the Cambridge B2 sense also includes improvement without replacement. Avoid falsely teaching replacement as mandatory.
- Proposed clearer English: “To make equipment, software or a system better, or replace it with a newer, better version.”
- Proposed Myanmar explanation: “စက်ပစ္စည်း၊ ဆော့ဖ်ဝဲ သို့မဟုတ် စနစ်တစ်ခုကို ပိုကောင်းအောင် ပြုပြင်မြှင့်တင်ခြင်း၊ သို့မဟုတ် ပိုမိုကောင်းမွန်သည့် ဗားရှင်းအသစ်ဖြင့် အစားထိုးခြင်း။”
- Original author-created example A: “The school upgraded its computers before the new term.” / “စာသင်နှစ်သစ်မစမီ ကျောင်းက ကွန်ပျူတာတွေကို အဆင့်မြှင့်တင်ခဲ့တယ်။”
- Original author-created example B: “We need to upgrade the payment system to improve security.” / “လုံခြုံရေး ပိုကောင်းလာစေဖို့ ငွေပေးချေမှုစနစ်ကို အဆင့်မြှင့်တင်ဖို့ လိုတယ်။”
- Grammar: transitive `upgrade + object` is supported; do not silently switch to the noun, which has a different UK stress pattern. Examples are original editorial proposals, not independently checked.
